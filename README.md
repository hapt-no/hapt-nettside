# hapt.no

Nettsiden til HAPT AS. Én statisk side (`index.html`) publisert med GitHub Pages på hapt.no.

- `fonts/` – Barlow (SIL Open Font License, se `fonts/OFL.txt`)
- `CNAME` – eget domene for GitHub Pages
- `verktoy/` – interne verktøy på hapt.no/verktoy (LED-vegg, projektor, testbilde, pixelmap, syncfilm, opptak, EDID, Stumpfl Vario). Ikke lenket fra forsiden, merket noindex og bak en enkel PIN-kode (`verktoy/las.js`, sjekkes i nettleseren, så den holder bare tilfeldige besøkende ute). Alt regnes ut i nettleseren.
